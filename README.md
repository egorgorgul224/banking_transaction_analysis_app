# Проект "Приложение для анализа банковских операций"

## Описание:
Проект представляет приложение для анализа транзакций, которые находятся в Excel-файле. 
Приложение может генерировать JSON-данные для веб-страниц, сервис по анализу кэшбека по категориям за выбранный месяц,
отчет по тратам по категории за 3 месяца и выгружать его в файл.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```
2. Перейдите в директорию проекта:
```
cd ваш_проект
```
3. Установите зависимости проекта:
```
poetry install
```

## Функции, примеры их использования и тесты:
### Функции для категории заданий «Веб-страницы»
1. Функция *get_excel_df* принимает на вход название excel файла и возвращает табличный формат файла(DataFrame).
Если название файла не указано, то принимает excel файл "operations.xlsx" в папке data. Если файл не был найден,
то вызывает исключение с сообщением "Файл не найден".

```
Вызов функции: get_excel_file("operations.xlsx")
Результат: DataFrame({}, {}, {}...)
```
Функция протестирована в модуле *test_file_reader* в папке **tests**. Также у функции обработано логирование в файл
*file_reader.log* в папке **logs**.

2. Функция *get_data_from_df* принимает на вход DataFrame файл и возвращает список словарей с данными.

```
Вызов функции: get_data_from_df("Имя_переменной")
Результат: [{}, {}, {}...]
```
Функция протестирована в модуле *test_file_reader* в папке **tests**. Также у функции обработано логирование в файл
*file_reader.log* в папке **logs**.

3. Функция *get_greeting* возвращает приветствие исходя из времени дня(ночь, утро, день, вечер).

```
Вызов функции: get_greeting()
Результат: с 6 до 12 - "Доброе утро", с 12 до 18 "Добрый день",
с 19 до 24 - "Добрый вечер", с 0 до 6 - "Доброй ночи"
```
Функция протестирована в модуле *test_views* в папке **tests**. Также у функции обработано логирование в файл
*views.log* в папке **logs**.

4. Функция *get_date_period* принимает на вход дату и время в формате YYYY-MM-DD HH:MM:SS(по умолчанию текущая дата
и время). Возвращает текущую дату и дату начала месяца в формате DD.MM.YYYY HH:MM:SS.

```
Вызов функции: get_date_period("2025-03-10 10:00:00")
Результат: 01.03.2025, 10.03.2025
```
Функция протестирована в модуле *test_views* в папке **tests**. Также у функции обработано логирование в файл
*views.log* в папке **logs**.

5. Функция *get_period_transactions* принимает список транзакций и период(начальную дату и конечную дату).
Возвращает список всех транзакций за данный период. Если переданный список пустой или за выбранный период нет
транзакций, то возвращает пустой список.

```
Вызов функции: get_period_transactions("Список_транзакций","01.03.2025", 10.03.2025)
Результат: [{}, {}, {}...]
```
Функция протестирована в модуле *test_views* в папке **tests**. Также у функции обработано логирование в файл
*views.log* в папке **logs**.

6. Функция *get_cards_number* принимает на вход список с транзакциями за выбранный период из функции
'get_period_transactions'. Возвращает список номеров всех карт за данный период в формате *XXXX, где X - число
от 0 до 9. Если список с транзакциями пустой, то возвращает пустой список.

```
Вызов функции: get_cards_number("Список_отсортированных_транзакций")
Результат: ["*0001", "*0002",...]
```
Функция протестирована в модуле *test_views* в папке **tests**. Также у функции обработано логирование в файл
*views.log* в папке **logs**.

7. Функция *get_cards_spent_cashback* принимает на вход список с транзакциями, список карт. Возвращает список суммы
трат и кэшбека по каждой карте. Если список транзакций или карт пуст, то возвращает пустые списки.

```
Вызов функции: get_cards_spent_cashback("Список_отсортированных_транзакций", "Список_карт_за_период")
Результат: [5000.0, 255.56,...], [50.0, 2.55,...]
```
Функция протестирована в модуле *test_views* в папке **tests**. Также у функции обработано логирование в файл
*views.log* в папке **logs**.

8. Функция *get_cards_info* принимает на вход списки номером карт в формате *XXXX, где X - число от 0 до 9,
список трат по картам  и список кэшбеков по картам. Возвращает список словарей с данными по
картам(карта, сумма трат, кэшбек). Если в переданных списках ничего нет, то возвращает пустой список.

```
Вызов функции: get_cards_info("Список_карт_за_период", "Список_трат_за_период", "Список_кэшбеков_за_период")
Результат: [{"last_digits": "0001", "total_spent": 5000.0,"cashback": 50.0}]
```
Функция протестирована в модуле *test_views* в папке **tests**. Также у функции обработано логирование в файл
*views.log* в папке **logs**.

месяце отсутствуют транзакции".

Вызов функции: get_categories_cashback_service("user_month", "user_year")
