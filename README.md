## Описание<a id="description"></a>
Проект представляет приложение для анализа транзакций, которые находятся в Excel-файле. 
Приложение может генерировать JSON-данные для веб-страниц, сервис по анализу кэшбека по категориям за выбранный месяц,
отчет по тратам по категории за 3 месяца и выгружать его в файл.

## Установка и настройка проекта<a id="instruction"></a>

1. Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```
2. Перейдите в директорию проекта:
```
cd ваш_проект
```
3. Установите зависимости проекта:
```
poetry install
```
4. Настроить файл .env.example. Добавить свои данные для работы с проектом.

## Информация по API сайтам<a id="api"></a>
1. Для функции, возвращающей курсы валют, используется API-запрос *Exchange Rates Data API* на сайте [apilayer.com](https://apilayer.com/marketplace/exchangerates_data-api)
2. Для функции, возвращающей стоимость акций, используется API-запрос *Stock Price -> Quote* на сайте [finnhub.io](https://finnhub.io/docs/api/quote)

Если название файла не указано, то принимает excel файл "operations.xlsx" в папке data. Если файл не был найден,
то вызывает исключение с сообщением "Файл не найден".

```
Вызов функции: get_excel_file("operations.xlsx")
Результат: DataFrame({}, {}, {}...)
```
Функция протестирована в модуле *test_file_reader* в папке **tests**. Также у функции обработано логирование в файл
*file_reader.log* в папке **logs**.

Возвращает список всех транзакций за данный период. Если переданный список пустой или за выбранный период нет
транзакций, то возвращает пустой список.

```
Вызов функции: get_period_transactions("Список_транзакций","01.03.2025", 10.03.2025)

Функция протестирована в модуле *test_views* в папке **tests**. Также у функции обработано логирование в файл
*views.log* в папке **logs**.

от 0 до 9. Если список с транзакциями пустой, то возвращает пустой список.

```
Вызов функции: get_cards_number("Список_отсортированных_транзакций")

## Запуск и тестирование проекта<a id="launch"></a>
1. После установки и настройки проекта перейти в модуль main в корне проекта.
2. Запустить его с помощью кнопки *run* или консоли *python/python3 main.py*.
3. Ввести дату в формате YYYY-MM-DD HH:MM:SS или пропустить ввод(используется текущая дата).
4. Ввести категорию, по которой хотите получить данные за 3 месяца.
5. Дождаться вывода результата в консоль. Если API-запрос будет длиться более 25 секунд, то вызовется исключение
*Timeout* с сообщением "Время запроса истекло".
